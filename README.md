Overview

VividFest is a dynamic web application designed to create an engaging festival experience for users, combining vibrant visuals with robust functionality.

Why VividFest?

This project aims to deliver a secure and interactive platform that enhances user engagement. The core features include:

🎉 User Authentication: Simplifies sign-up and login with email, Google, and GitHub for a secure experience.
📱 Responsive Design: Ensures seamless usability across devices, making the application accessible to all users.
🌟 Dynamic User Interface: Leverages React and animations for an engaging and interactive user experience.
🔄 Real-time Data Handling: Integrates with Firebase for efficient data management and user state monitoring.
🤝 Community Engagement: Focuses on authenticated users to foster a sense of belonging and enhance retention.
Getting Started

Prerequisites

This project requires the following dependencies:

Programming Language: HTML

Installation

Build vividfest from the source and intsall dependencies:

Clone the repository:

❯ git clone https://github.com/infinity-events/vividfest
Navigate to the project directory:

❯ cd vividfest
Install the dependencies:

Using npm:

❯ npm install
Usage

Run the project with:

Using npm:

npm start
Testing

Vividfest uses the {test_framework} test framework. Run the test suite with:

Using npm:

npm test
